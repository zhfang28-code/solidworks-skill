# 工程图解析与特征规划

## 读取顺序

1. 读取图签：零件号、名称、材料、比例、单位、投影法、版本和标准。
2. 识别主视、剖视、端视、局部放大和剖切方向，确定同一几何在不同视图中的对应关系。
3. 读取总体尺寸，再读取台阶、孔槽、角度、圆角、倒角和重复特征。
4. 读取公差带、形位框格、基准符号、粗糙度、热处理、齿轮/花键表和技术要求。
5. 检查尺寸链是否闭合，区分直接标注值和计算所得值。

## 参数台账

为每个任务建立参数台账，至少包含：

| 字段 | 含义 |
|---|---|
| ID | 稳定参数名，如 `overall_width_mm` |
| 图纸值 | 原始标注，保留公差和符号 |
| 名义值 | 用于建模的基本尺寸 |
| 单位 | mm、°、HRC 等 |
| 来源 | 视图、表格或技术要求位置 |
| 类型 | 实体驱动、派生、属性、检验或歧义 |
| 状态 | 已确认、计算、待确认 |
| 备注 | 假设、标准或计算式 |

关键尺寸必须保留原始字符串，例如 `Ø35H7`、`14 f9`、`21.36 0/-0.05`，不能只留数值 35、14、21.36。

## 几何与非几何信息

- 以基本尺寸创建名义实体。除非用户要求极限尺寸模型，不要把公差中值或上/下极限默默写入草图。
- 表面粗糙度、硬度、热处理、齿轮精度和检验允许值通常是制造/计量信息，应进入自定义属性、审核报告和检验表。
- 形位公差需要基准体系和测量方案。CAD 中可创建基准几何和注解，但不能仅凭实体判断检验合格。
- 材料库没有图纸牌号时，可选择明确标注的近似材料用于理论质量；在聊天窗口、属性和 BOM 同时披露替代关系。

## 特征选择

| 图纸特征 | 首选建模方式 | 审核重点 |
|---|---|---|
| 回转轴、套、盘 | 半剖面旋转；简单等径件可拉伸 | 轴线、台阶位置、总长 |
| 法兰、板、支架 | 基体拉伸 + 孔/切除 | 厚度、对称关系、孔距 |
| 周向重复孔槽 | 单个种子 + 圆周阵列 | 数量、角度、种子方向 |
| 线性重复特征 | 单个种子 + 线性阵列 | 节距、方向、终止条件 |
| 螺纹 | 装饰螺纹或真实螺旋线，按用途选择 | 标准、牙型、性能成本 |
| 齿轮/花键 | 参数生成真实轮廓或经确认的简化表示 | 模数、齿数、压力角、齿厚、根部 |
| 铸造/自由曲面 | 放样、边界、曲面缝合/加厚 | 连续性、封闭性、拔模 |

## 歧义处理

以下情况必须在聊天窗口先报告，不得自行补齐：

- 关键轮廓缺少宽度、深度、起止位置或角度作用范围。
- 多个视图对同一尺寸互相矛盾。
- `未注倒角 Cx`、圆角或表面要求无法确定具体适用边。
- 标准号可识别，但等级、配合对象、测量跨距或刀具参数缺失。
- 图像分辨率不足，关键数字存在两个以上合理读法。
- 由尺寸链可推导但会影响装配配合或加工余量。

可继续构建不受影响的部分，但必须把未决项隔离，并说明它是否阻止最终放行。

## 草图与特征树质量

- 使用固定原点、中心线、同心、对称、水平/垂直和尺寸约束，使草图完全定义。
- 用基准面和明确偏置定位轴向特征，不依赖会随拓扑变化的面。
- 将圆角、倒角放在主体几何稳定之后。
- 用编号和含义命名，例如 `01_回转基体_Ø46×40`、`04_内孔_贯通切除`。
- 对有方向性的切除、拔模和倒角，在创建后立即用截面或侧视确认方向。
