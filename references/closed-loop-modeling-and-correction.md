## 核心不变量

1. 构建前先确认绝对保存路径。
2. 图纸直接值、派生值、设计假设和制造要求分开记录。
3. 每轮只修改一个错误零件；其余零件哈希必须不变。
4. 候选件不得直接覆盖正式件。
5. 每次修改都要重新装配、检查干涉、刷新质量、STEP、BOM 和同一组五视图。
6. API 返回对象不等于几何或工程图正确；必须用包围盒、B-rep、保存重开和渲染证据复核。
7. 默认项目只能保留一个有效模型集；最终目录外残留模型时不得交付。
8. 无法唯一确定的尺寸或轮廓必须在聊天窗口标为“技能外事项 / 待确认”，不得静默补值。

## 阶段 0：锁定输入与保存位置

1. 只读检查图纸、现有模型、SolidWorks 版本、模板和目标目录。
2. 在启动 SolidWorks 或写模型前询问并等待用户确认绝对保存路径。
3. 约定：
   - 项目根目录；
   - 唯一最终目录；
   - 主文件基名；
   - 是否允许保留历史模型；
   - 原生文件、STEP、工程图、PDF、五视图和 BOM 的交付范围。
   - 错误台账固定路径：`<project-root>\审核资料\<项目>_建模错误与解决记录.md`。
4. 复制或保留原始图纸作为不可变基线，记录文件哈希。
5. 若目标已有同名模型，先建候选修订目录，不覆盖。

## 阶段 1：图纸解析与零件拆分

1. 按图签、明细栏、序号引线和剖面边界建立 BOM 草表。
2. 将每项尺寸写入参数台账：原始字符串、名义值、单位、来源视图、类型、状态和备注。
3. 建立视图映射：参考正面、侧面、俯视、剖面分别对应模型的哪个标准方向。
4. 对每个零件冻结：
   - 原点、中心面、轴线和安装面；
   - 基体与有序特征树；
   - 接触面、配合面和装配功能基准；
   - 直接尺寸与缺失尺寸。
5. 先在聊天窗口输出会改变拓扑、配合或外轮廓的歧义。

不得把装配图中看得到但没有唯一尺寸的曲线，当成已经确认的零件轮廓。

## 阶段 2：零件建模

### 通用顺序

1. 基体；
2. 增材台阶、法兰、凸耳或筋；
3. 孔、槽、相贯和贯穿切除；
4. 阵列；
5. 倒角、圆角、球冠或自由曲面；
6. 螺纹/材料/零件号等属性；
7. 强制重建与单件审查。

### 每件必查

- 预期实体数；
- 包围盒和关键总尺寸；
- 孔槽方向及贯穿条件；
- 曲面类型与数量；
- 体积、质量和材料密度来源；
- 草图命名、尺寸和自由度；
- 等轴测与至少两个正交方向预览；
- 保存错误码和警告码。

### 曲面和切除防错

- 图纸要求球面或圆弧球冠时，优先用轴向圆弧旋转；不得用拔模锥面冒充。
- `InsertDome`、拔模或圆角即使未报错，也要检查包围盒高度、球面/圆锥面计数和轮廓预览。
- 贯穿孔必须显式检查方向。需要双向贯穿时两个方向均设为 `ThroughAll`。
- 平板与圆筒无缝贴合时创建同径鞍形/相贯面，不用中心线顶点相切代替全厚接触。
- 避免毛坯与切除面只形成点或线接触，防止零厚度几何。

### 表达边界

- 螺纹可按任务采用装饰螺纹或名义圆柱，但必须披露未实体化牙型。
- 粗糙度、公差、硬度和热处理进入属性、工程图或检验表，不当作草图实体尺寸。
- 完全定义尝试返回值不能证明自由度为零；需要逐草图复核。

## 阶段 3：装配与显示

1. 先预加载零件，再插入装配体。
2. 固定最稳定的基准件；其余组件使用功能基准配合或已披露的公共坐标定位。
3. `AddComponent5` 坐标按包围盒中心处理，不当作零件原点平移。
4. 修改轮廓后重新以轴线、中心面或安装面定位，不继续依赖变化的包围盒最小值。
5. 强制重建并检查：组件数、解析/轻化/抑制状态、总包络、干涉和接触。
6. 螺钉、销和轴端定位要检查端面，不允许靠目测坐标产生穿透。

### 清晰显示

- 零件使用浅色、低饱和、相邻件明度不同的配色。
- 审核视图使用“带边线上色”或“消除隐藏线”。
- 俯视/剖视发黑时先关闭上色阴影、环境光遮蔽和 RealView，再调整定向光源；不要用灯光掩盖真实缝隙。
- 三维剖面可用浅色剖面盖；正式工程图保持白底黑线，以剖面线角度和间距区分零件。

## 阶段 4：工程图与剖视

1. 从明确的标准/命名视图创建正投影视图，不用任意相机方向冒充。
2. 创建真实剖切线并确认它穿过目标实体。
3. `View.GetOutline()` 是图纸页坐标，视图草图是局部模型坐标；换算使用：

```text
local = (sheetCoordinate - viewCenter) / view.ScaleDecimal
```

4. 确认剖切方向与参考图一致；底/顶或左/右倒置即失败。
5. 轴、杆、销和紧固件在纵向装配剖视中按图示约定不剖；肋板沿长度方向剖切时同样复核制图表达。
6. 最后一次重建后再设置不剖件面填充：

```text
UseMaterialHatch = false
HatchScope = Region
HatchType = None
```

7. 保存、关闭并重新打开 `SLDDRW`，再次统计：剖视类型、剖切线数、可见组件数、有效面剖面数和被取消填充的组件。
8. 组件排除 COM 接口调用成功不能作为结果证据；它可能无效或触发服务端异常。最终以重开后的图纸和 PDF 渲染为准。

## 阶段 5：固定五视图对图

每个候选版输出完全相同的证据组：

1. 正面；
2. 侧面；
3. 俯视；
4. 3D 等轴测；
5. 剖面。

逐视图比较：总体轮廓、零件分界、孔槽台阶、直接尺寸、接触关系、隐藏/中心线和剖面约定。记录：参考要求、模型证据、差异、疑似零件、疑似特征/尺寸和状态。

状态只用：

- `通过`：模型/文件直接证明；
- `失败`：存在明确不一致；
- `待确认`：参考图不足以唯一确定。

3D 等轴测只证明连接关系和可见干涉，不代替正投影尺寸审核。

## 阶段 6：单零件事务式修订

### 修订前

1. 保存装配体、全部零件和工程图的路径、配置、组件变换与 SHA-256。
2. 从差异表中只选择一个目标零件和一个明确问题集合。
3. 把其他差异留在下一轮，不同时改第二个零件。
4. 将目标件复制/重建为临时候选文件；正式件保持不动。

### 候选件验证

1. 重建无错误；
2. 实体数、包围盒、曲面类型、关键尺寸正确；
3. 体积/质量刷新；
4. 预览与参考局部轮廓一致；
5. 无零厚度且可导出。

### 候选装配验证

1. 只替换目标组件；
2. 组件数、配置和变换正确；
3. 轻化/抑制状态正确；
4. 干涉为允许值；
5. 总包络和调节位置正确；
6. 重新生成同一组五视图、真实剖视和 STEP；
7. 刷新 BOM；
8. 未修改零件哈希与修订前完全相同。

候选装配未通过时，不删除正式错误件；记录失败、原因和下一步。

## 阶段 7：提升正式版本与删除旧模型

### 提升顺序

1. 候选单件通过；
2. 候选装配通过；
3. 五视图和剖视通过；
4. STEP 独立回读通过；
5. BOM 与质量刷新；
6. 记录最终哈希；
7. 删除错误正式件并把候选件提升为正式路径；
8. 再保存/验证装配体、工程图和清单。

### 项目级旧模型清理

默认只允许唯一最终目录保留以下扩展名：

```text
.SLDPRT .SLDASM .SLDDRW .STEP .STP
```

删除前必须：

1. 解析项目根目录和最终目录的绝对路径；
2. 确认最终目录位于项目根目录内；
3. 枚举最终目录外的候选旧模型并计算哈希；
4. 确认最终模型数量和哈希；
5. 对候选旧模型执行独占文件锁检查；
6. 确认最终装配审查记录指向最终目录；
7. 不结束无法证明归属的 SolidWorks 进程。

只逐文件、按绝对路径删除已确认旧模型；不得对项目根目录、用户目录或不明计算路径执行递归删除。删除后再次全项目扫描，要求最终目录外模型数为 0。

旧 PNG、PDF、日志、JSON、BOM 和源代码可保留追溯。若用户要求把历史模型也保留，必须在聊天窗口说明将存在多个有效模型集，并取消“唯一最终模型”结论。

### 临时编译目录清理

- 项目专用正式源码保留在 `<project-root>\重建工具源`；先确认其中包含最新 builder、检查器和修订脚本。
- `rebuild_tool_yyyyMMdd_HHmmss_fff` 是编译副本，不是模型或正式源码。成功构建且无进程从中运行时应清理；失败版本只保留到根因记录完成。
- 清理前验证目录位于确认的项目根目录或 BuildRoot 内、名称严格匹配、不是重解析点，并确认内部没有 `SLDPRT/SLDASM/SLDDRW/STEP/STP`。
- 不删除 `重建工具源`，不把临时 EXE/DLL 放入最终交付目录。若需要复现历史二进制，使用 `-KeepBuildDirectory` 并在聊天窗口披露。

## 阶段 8：BOM、清单和聊天披露

1. 从最终重建实体重新读取单重；不得沿用修订前质量。
2. BOM 总重使用公式 `数量 × 单重`，渲染全部工作表并扫描公式错误。
3. STEP 重新打开并记录文档类型、组件/实体数和错误码。
4. 运行项目级门禁：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass `
  -File scripts/Test-SolidWorksDelivery.ps1 `
  -OutputDirectory '<project-root>\<final-directory>' `
  -ProjectRoot '<project-root>' `
  -RequireNoModelsOutsideOutput `
  -BaseName '<base>' `
  -DocumentType Assembly `
  -RequireBom `
  -WriteManifest -Force -AsJson
```

5. 只有 `MissingRequired.Count=0`、`ModelSetHygiene.OutsideModelCount=0` 且 `Ready=true` 才能交付。
6. 最终聊天列出主模型、STEP、工程图/PDF、五视图对图报告、BOM、错误日志和“技能外事项 / 待确认”。

## 错误台账模板

建模开始即创建台账，按发现顺序使用 `E001`、`E002`……追加；不得删除失败记录或因最终成功而改写历史。每一条至少包含：

| 字段 | 内容 |
|---|---|
| 编号/时间 | 唯一错误编号、发现时间和修复时间 |
| 阶段/对象 | 图纸解析、零件、装配、工程图、导出或自动化；文件与特征名 |
| 现象/影响 | 可复现的错误表现及受影响交付件 |
| 预期/证据 | 图纸要求、尺寸来源或正确基准 |
| 根因 | 几何、坐标、API、文件版本、显示或流程原因；未知时写“待确认” |
| 修复动作 | 本轮只修改的零件/特征和正式文件是否保持不动 |
| 验证证据 | 重建、实体数、包围盒、干涉、五视图、剖视、STEP、BOM、哈希等结果 |
| 状态 | `未修复`、`候选验证中`、`已修复待交付`、`已关闭` 或 `待确认` |
| 防再犯 | 转化出的检查项、脚本门禁或仍需人工确认的动作 |

修复失败也要单独追加记录。若失败尝试改动了正式文件，先恢复已记录哈希对应版本，再开始下一轮候选修订。

## 高频错误与强制防错

| 错误 | 根因 | 强制防错 |
|---|---|---|
| 圆顶高度正确但曲面错误 | 用拔模锥面近似球冠 | 检查球面/圆锥面计数和剖面轮廓 |
| `InsertDome` 无报错但包络未变化 | 特征未真正形成有效几何 | 每特征检查返回对象、包围盒和实体 |
| 通孔造成大体积干涉 | 只切一侧或方向反了 | 显式双向 `ThroughAll` 并做剖面复核 |
| 螺钉穿入轴/杆 | 目测坐标定位 | 检查端面与干涉体积 |
| 肋板与圆筒边缘有缝 | 只在中心顶点相切 | 同径鞍形相贯面 + 全板厚近景 |
| 剖视对象存在但剖面为空 | 页坐标直接用于局部草图 | 使用中心/比例坐标换算，验证填充数 |
| 剖面上下倒置 | 剖切方向反向 | 与参考图固定方向对照 |
| 不剖件重建后又出现填充 | 无填充设置早于最后重建 | 最终重建后设置并保存重开 |
| 组件排除调用失败/崩溃 | COM 版本差异 | 用稳定几何匹配 `FaceHatch`，以视觉结果为准 |
| 俯视图发黑看不清 | 阴影、环境光遮蔽、RealView 叠加 | 关闭显示效果，使用浅色和边线 |
| 一个错误牵连多个零件 | 同轮大范围重建 | 哈希冻结，一轮只替换一个零件 |
| BOM 仍是旧重量 | 几何修改后未刷新质量 | 从最终实体重算并扫描公式 |
| STEP 名称正确但内容是旧版 | 覆盖/导出失败后沿用旧文件 | 新路径导出并独立回读 |
| 最终目录正确但项目仍有旧模型 | 交付脚本只检查必需文件 | 启用项目根目录唯一模型门禁 |
| 大量 SW 后台进程 | COM 未释放或异常退出 | 记录自有 PID；不广泛强杀未知会话 |
| `.ps1` 无法加载 | 当前 PowerShell 执行策略禁止脚本 | 用独立 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File ...` 调用；不修改机器级策略 |
| 项目出现多个 `rebuild_tool_*` | 编译目录放在模型目录且成功后未清理 | 正式源码集中保存；临时根目录隔离；成功后自动清理 |

每次出现新错误都追加到错误台账，并判断能否转化为脚本门禁；可自动检查的错误不得只保留为文字提醒。

## 最终验收门禁

- [ ] 保存位置已确认，最终目录唯一。
- [ ] 参数台账区分直接、派生、假设和制造要求。
- [ ] 每个零件实体数、包围盒、关键尺寸和质量通过。
- [ ] 装配组件数、状态、基准、接触和干涉通过。
- [ ] 正面、侧面、俯视、3D、剖面均已与参考图对照。
- [ ] 剖视保存重开后仍有效，不剖件表达正确。
- [ ] 单零件修订时其他零件哈希不变。
- [ ] STEP 独立回读通过。
- [ ] BOM 从最终实体刷新，公式错误为 0。
- [ ] 最终目录外模型数为 0，或历史模型保留已获明确授权并披露。
- [ ] 错误台账包含现象、原因、修复和证据。
- [ ] 正式 builder 源码已集中保存，交付目录无 `rebuild_tool_*` 临时编译目录。
- [ ] `Ready=true` 后才输出完成结论。
