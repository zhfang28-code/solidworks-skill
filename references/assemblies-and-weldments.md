## 适用范围

用于机械装配图、板焊支架、管板/肋板连接、固定焊接总成，以及需要复核组件位置、接触、间隙或干涉的任务。

## 1. 先拆件，再建模

1. 从明细栏、序号引线和剖面线识别零件边界。
2. 建立零件表：零件号、名称、数量、材料、板厚/直径、来源视图和缺失尺寸。
3. 区分直接尺寸与派生尺寸。派生式必须进入参数台账，例如 `圆筒长度 = 装配总深 − 立板厚度`。
4. 图纸没有独立零件图时，将派生尺寸标为“待设计确认”，不要把装配推导结果当作已发布制造尺寸。

不要把焊缝、剖面填充、相邻零件轮廓或断裂画法误识别为同一零件实体。

## 2. 冻结公共坐标与装配基准

对整个项目使用一个可解释的坐标系，例如：

- X：正视宽度；
- Y：高度；
- Z：装配深度/圆筒轴向。

选择最稳定的主体板或机架作为固定基准件。为每个组件记录功能基准，而不是只记录包围盒：

| 组件 | 推荐功能基准 |
|---|---|
| 立板/机架 | 原点、中心面、安装面 |
| 横板 | 与立板接触端面、板底/板顶面、中心面 |
| 肋板 | 中面、横板底面、圆筒轴线/贴合面 |
| 圆筒 | 轴线、前端面、外圆柱面 |

零件轮廓修订后，包围盒最小值可能变化。继续用 `目标最小值 − 当前最小值` 定位会移动整个零件；优先使用不变的顶面、轴线、中心面或草图原点。

## 3. 零件特征策略

- 立板：正视外轮廓拉伸板厚，再切安装孔和功能孔。
- 横板：上视矩形拉伸板厚，再切孔；板面深度可由装配尺寸链派生。
- 肋板：右视/侧视轮廓拉伸板厚；先形成稳定毛坯，再建立相贯或鞍形切除。
- 圆筒：同心圆拉伸，明确外径、内径和实体长度。

保持每件一个预期实体。给草图和特征命名，示例：`01_肋板毛坯_拉伸8`、`02_圆筒贴合面_Ø40贯穿切除`。

## 4. 平板与圆筒贴合：必须做三维检查

若板厚为 `t`、圆筒半径为 `R`，把板底做成位于圆筒顶点 `Y=R` 的平面，只会在板宽中心形成线接触。板边 `X=±t/2` 的理论竖向缝隙为：

```text
gap = R - sqrt(R² - (t/2)²)
```

例如 Ø40 圆筒与 8 mm 肋板：

```text
gap = 20 - sqrt(20² - 4²) ≈ 0.404 mm
```

因此“正中剖面看起来相切”仍可能在板厚两侧存在可见缝隙。

需要无设计间隙时：

1. 将肋板毛坯延伸进入圆筒外包络少量距离。
2. 在垂直圆筒轴线的基准面画与圆筒同轴、同直径的圆。
3. 沿圆筒轴向贯穿切除，形成 ØD 鞍形圆柱面。
4. 以横板底面/圆筒轴线等功能基准重新定位肋板。
5. 用正视图确认轮廓连续，用等轴测近景确认整个板厚范围无缝，再做干涉检查。

可先运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/Test-PlateCylinderContact.ps1 `
  -CylinderDiameterMm 40 -PlateThicknessMm 8 -ContactType FlatTangent -AsJson
```

### 避免零厚度与尖点

- 相贯切除后的尾端若恰好只剩一点或一条边，可能产生零厚度/不可导出几何。
- 让毛坯在切除面外保留明确厚度，或让斜边与圆柱面形成稳定交线。
- 每次修改后检查实体数量、重建错误、体积是否为正以及 STEP/Parasolid 导出能力。

## 5. 装配方式选择

### 固定坐标装配

适用于焊接件、教学模型和无需运动的刚性总成：

1. 固定主体板。
2. 按公共坐标插入其余零件。
3. 记录每个组件平移/旋转和功能基准。
4. 在属性和报告中明确“固定坐标装配”，不要声称已经建立设计配合。

### 配合装配

用于需要表达设计意图、运动或替换零件的总成：

- 端面：重合/距离配合；
- 孔轴：同心配合；
- 居中：宽度或中心面重合；
- 焊接后锁定：锁定旋转或固定组件。

不要用大量固定组件掩盖错误自由度，也不要把焊接接触自动等同于焊缝实体。

## 6. SolidWorks API 装配要点

- `AddComponent5` 前先用 `OpenDoc6` 预加载零件。
- 插入坐标是组件包围盒中心位置，不是零件原点平移量；先求零件包围盒中心，再叠加目标变换。
- 插入后重新激活装配体、检查返回的 `Component2`，再固定或添加配合。
- 强制重建后检查组件数量、抑制/轻化状态和每个 `ModelDoc2` 是否可解析。
- 颜色使用明亮低饱和粉彩，至少保证相邻零件有色相或明度差；最终审核仍以边界和剖面为准。

## 7. 推荐装配与焊接顺序

1. 固定主体板或机架。
2. 用芯轴或同心配合定位圆筒与功能孔。
3. 定位横板并复核总体尺寸和孔距。
4. 居中肋板，检查其与横板、主体板、圆筒的接触。
5. 点固后对称、分段施焊以控制变形；焊脚、坡口、间隙和顺序由焊接工艺规程决定。
6. 焊后复核功能孔、轴线、总包络和安装面。

CAD 只表达名义装配关系。烧穿、咬边、硬度、焊透和实际变形必须由工艺/检验确认。

## 8. 常见错误与恢复

| 错误 | 原因 | 处理 |
|---|---|---|
| 肋板与圆筒边缘有缝 | 只建立顶点相切平面 | 用同径圆柱贯穿切除形成鞍形面 |
| 修订后肋板整体上移 | 用变化后的包围盒最小 Y 定位 | 改用横板底面、轴线或中心面定位 |
| 装配组件位置异常 | 把 `AddComponent5` 坐标当作原点平移 | 传入目标包围盒中心并验证实际包围盒 |
| 插入组件失败/轻化 | 未预加载零件或装配体未重新激活 | `OpenDoc6` 预加载、激活装配体、解析轻化组件 |
| 原生模型保存但 STEP 失败 | 导出器、残留会话、锁文件或几何问题 | 保留原生文件，记录错误码；安全退出会话后重试并独立验证 |
| 多个 SolidWorks 进程残留 | COM 引用未释放或异常退出 | 关闭本任务文档、`ExitApp`、释放 COM；不得广泛强杀用户会话 |
| 修改覆盖旧成果 | 直接写入已有目录 | 默认新建语义清晰的修订子目录并保留旧交换文件 |

STEP 失败不能被记录为成功。可以继续保存并审核原生模型和预览，但最终聊天与交付清单必须把 STEP 标为失败/待补导。

## 9. 单零件纠错与重新装配

1. 在修改前计算装配体及全部零件的 SHA-256，并记录当前组件路径、配置和变换。
2. 从五视图差异中只选一个错误零件，明确错误特征或尺寸；其他差异留到下一轮。
3. 将候选修正版保存为临时文件，不直接覆盖正式 `SLDPRT`。
4. 单件验证实体数、包围盒、关键尺寸、质量属性和预览；然后用该候选件重装配并检查组件数、轻化/抑制状态、总包络和干涉。
5. 重新输出同一组正面、侧面、俯视、3D 和剖面视图，对照参考图复核。
6. 全部通过后才删除错误正式零件并把候选件提升为正式文件；随后重新保存装配体、工程图、STEP、BOM 和清单。
7. 最后再次计算全部零件哈希。除目标零件外，其他零件哈希必须与修改前一致；否则停止交付并调查意外改写。

装配图缺少能唯一确定某个轮廓的尺寸时，不得在同一轮顺带修改另一个零件。将其作为下一轮候选并在聊天窗口要求零件图或设计确认。
